# micronaut-server-netty sample ownership

[English](README.md) | [简体中文](README.zh-CN.md)

This module supplies the Netty HTTP server transport. The runnable scenario is owned by [micronaut-web](https://github.com/normlanguage/micronaut-web/tree/main/samples) in its `samples/` directory; use that example to observe the behavior through the public API.

The module identity and pinned dependencies are defined in [module.norm](../micronaut/server/netty/module.norm).
