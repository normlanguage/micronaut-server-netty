# Micronaut HTTP Server Netty

[English](README.md) | [简体中文](README.zh-CN.md)

The adapter declaration and runnable example are in `micronaut/server/netty`. It pins Micronaut HTTP Server Netty 5.1.13 and defines its package coordinates in [module.norm](micronaut/server/netty/module.norm). This module provides the official Netty server implementation and its runtime dependencies.
